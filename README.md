# Leads Finder Bot

Телеграм-бот, который ищет на карте (OpenStreetMap) бизнесы **без сайта** и со **слабым сайтом**,
а потом помогает взять клиента: готовые тексты для директа, звонка и email (RU / EN / FI),
ответы на возражения и план сделки. Всё бесплатно: Telegram + OpenStreetMap + Vercel (Hobby).

## Что внутри
```
api/webhook.py   весь бот (поиск, оценка сайтов, скрипты)
vercel.json      лимит выполнения 60 секунд
set_webhook.py   подключение бота к Vercel одной командой
.env.example     пример переменных
```

## Запуск за 6 шагов
1. В Telegram открой @BotFather, команда `/newbot`, получи токен.
2. Создай репозиторий на GitHub и загрузи туда все файлы из этого архива.
3. На vercel.com: Add New -> Project -> выбери репозиторий -> Deploy.
4. Vercel -> Settings -> Environment Variables. Добавь:
   - `BOT_TOKEN` и `WEBHOOK_SECRET` (обязательно)
   - `MY_NAME`, `MY_CONTACT`, `MY_PORTFOLIO`, `MY_PRICE`, `DEFAULT_LANG` (твои данные для текстов)
   Потом Deployments -> Redeploy.
5. Подключи вебхук (на своём компьютере установлен Python), либо открой ссылку в браузере:
   `python set_webhook.py <BOT_TOKEN> https://<проект>.vercel.app <WEBHOOK_SECRET>`
   или
   `https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=https://<проект>.vercel.app/api/webhook&secret_token=<WEBHOOK_SECRET>`
6. Напиши боту `/start`.

## Как пользоваться
1. Выбираешь нишу, режим (без сайта / слабый сайт / всё вместе) и пишешь город.
2. Получаешь карточки: оценка сайта, проблемы, телефон, что предложить.
3. Под карточкой жмёшь **«✍️ Скрипты и подсказки»**:
   - 📱 Директ / WhatsApp: основной и короткий текст
   - 📞 Звонок: приветствие, зацепка, предложение, закрытие, что сказать секретарю
   - ✉️ Email: тема и текст
   - 🔁 Follow-up: напоминания через 2–3 и 7 дней
   - 🛡 Возражения: «дорого», «не нужно», «подумаем», «уже есть», «хватает соцсетей», «сайт нормальный»
   - 📋 План сделки: шаги от подготовки до закрытия
   - переключатель языка текстов 🇷🇺 🇬🇧 🇫🇮
4. Команды: `/tips` (общие советы), `/me` (твои данные в текстах), `/help`.

## Как оценивается сайт (0–100, выше значит хуже)
нет адаптива +25, нет HTTPS +20, проблема SSL +30, заглушка +40, устаревший копирайт +15,
древняя вёрстка +20, старый jQuery +10, медленная загрузка +10, нет SEO-описания +5, почти пустая страница +15.
Сайт не открывается: 65. Соцсеть вместо сайта: 55. Слабым считается балл от 30 (`WEAK_MIN`).

## Как править
- Тексты скриптов: словарь `T` в `api/webhook.py`. Переменные: `{biz} {me} {domain} {problem} {pricep} {portfolio} {contact}`.
- Ниши: словарь `NICHES` (теги OpenStreetMap).
- Размер страницы и порог: `PAGE`, `WEAK_MIN`, `MAX_ANALYZE` в начале файла.

## Важно
- Данные OpenStreetMap неполные: «нет сайта» значит «нет сайта в OSM». Проверяй кнопкой «Проверить в Google».
- Холодные сообщения и звонки регулируются законами (GDPR и местные правила о маркетинге). Пиши вручную, по делу и не спамь.
- Бот ничего не хранит между запросами. Чтобы вести базу клиентов, можно подключить бесплатный Upstash Redis или Supabase.
